# 哪吒仙饮模拟器
##一个平平无奇的商科模拟沙盘工具

设计思路：
一、先明确：沙盘要模拟什么

商科体验课适合的沙盘本质上是简化版的经营决策模拟，核心循环是：
每组拥有一家公司 → 每轮做决策（定价、进货、营销投入等）→ 导师公布市场结果 → 结算盈亏 → 排名变化 → 进入下一轮
一般跑4-6轮，每轮15-20分钟，正好填满90分钟的实战环节。决策要控制在3-4个变量以内，多了高中生会卡壳。

二、活动形态

1. 纸质桌游式沙盘（最推荐，半天课首选）
成本低、氛围好、无技术故障风险，动手操作的"体感"最强。每组一套：
表格


物料	说明	单组成本
决策卡	每轮填写：定价、进货量、营销投入	几元
代币/筹码	代表启动资金（如100万虚拟币）	10-20元
库存卡	代表商品数量（可用扑克牌、积木块代替）	几元
经营记录表	每轮记录收入、成本、利润、现金余额	打印费
市场事件卡	导师随机抽取："原材料涨价20%""竞品大幅降价"——制造戏剧性和讨论点	打印费
计分白板/龙虎榜	教室前方实时更新各组排名，这是制造竞争氛围的核心	白板或打印

三、赛题设定建议（沙盘和命题是一体的）

选学生有体感的行业，规则一眼能懂：
校园奶茶店经营：定价、进原料量、营销投入三变量，天气事件卡（"下雨天客流减半"）——最经典，实测效果最好；
校园咖啡店/文创店：同上逻辑，可叠加"选址"决策；
二手书交易平台：适合想植入互联网/平台概念的高年级场。
数值设计要点：
初始资金 = 约2轮的全额投入，逼学生取舍；
每轮留出"破产风险"的可能（市场容量有限、库存过期），有淘汰才有刺激；
第3轮后放一张"黑天鹅"事件卡，把气氛推到最高点；
