# 奶茶大亨 · 多人商业经营沙盘

面向商科体验课的浏览器多人经营模拟。教师创建教室并控制回合，学生以公司/队伍身份加入，在每轮完成定价、进货和营销决策；教师统一揭晓市场事件、结算利润并组织复盘。

## 课堂流程

1. 教师打开网页，选择「我是教师」，填写教室名称和经营轮数。
2. 系统生成 6 位教室号；教师将教室号或邀请链接发给学生。
3. 学生打开同一个 GitHub Pages 地址，选择「我是学生」，输入教室号并创建公司。
4. 教师确认公司席位后开始比赛。学生每轮在自己的设备上提交一次决策。
5. 全员提交后，教师揭晓突发事件并统一结算；现金余额与排名会同步到所有设备。
6. 终局后教师可导出 CSV，其中包含每支公司的每轮决策、销量、损耗、利润和最终排名。

## 为什么不使用 localhost IP

GitHub Pages 页面通过 HTTPS 打开，直接访问教师电脑上的 `http://localhost` 或局域网 IP 会遇到浏览器混合内容限制；而且 `localhost` 在学生设备上指向的是学生自己的设备，并不是教师电脑。

本项目采用 WebRTC 数据通道：

- 免费 PeerJS Cloud 只负责建立连接时的信令握手；
- 开局后的决策、结算和排行榜由学生浏览器与教师浏览器直接传输；
- 教师浏览器是唯一权威结算端，不需要自建业务后端或数据库；
- 教师必须保持控制台页面开启，所有设备也需要能够访问互联网。

如果校园网络严格限制 WebRTC，建议课前用教师热点试跑。需要跨复杂网络、断线后长期恢复或保存历史班级数据时，下一阶段可改接 Firebase/Supabase 等托管实时数据库。

## 本地预览

不要直接双击 HTML 文件。可在项目目录启动任意静态文件服务，例如：

```bash
python3 -m http.server 8080
```

然后访问 `http://localhost:8080`。多人联调时，可分别使用普通窗口和无痕窗口模拟教师与学生。

## GitHub Pages 部署

项目没有构建步骤，仓库根目录即为可部署站点。在 GitHub 仓库的 **Settings → Pages** 中选择从分支部署，分支选择 `main`、目录选择 `/ (root)`。此后提交到 `main` 的 `index.html`、`styles.css` 和 `app.js` 会直接发布。

## 文件说明

- `index.html`：教师端、学生端和身份入口的页面结构
- `styles.css`：响应式视觉设计
- `app.js`：房间连接、权威结算、事件系统、排行榜和 CSV 导出
- `public/og.png`：分享 GitHub Pages 链接时使用的预览图
- `活动流程表.xlsx`：线下课程流程参考

## 课堂规则

- 初始资金：¥1,000
- 每轮固定成本：¥120
- 基础原料成本：¥4/杯
- 决策变量：售价 ¥8–24、进货 0–200 杯、营销 ¥0–200
- 当轮未售出的鲜奶全部损耗；现金可以因市场事件或经营亏损变为负数
- 市场份额由价格吸引力和营销效率共同决定，事件还可能改变市场容量、价格敏感度、成本或可售库存
